# Evidencias de ejecucion (por completar)

Este directorio no incluye capturas fabricadas. Una vez que se ejecute el proyecto
en Codespaces, agregar aqui:

1. Captura del repositorio de GitHub y del README.
2. Terminal con `docker build` terminado correctamente.
3. `docker ps` mostrando el contenedor en ejecucion.
4. Navegador con el formulario y una inferencia real.
5. Pantalla de `/docs` y resultado de `bash scripts/smoke_docker.sh`.
6. Resultado real de GitHub Actions si se ejecuta el flujo manual de Docker.

Se puede ejecutar `bash scripts/registrar_validacion.sh` para guardar un registro
textual local (sin datos personales). Los logs solo se consideran evidencia real
si provienen de una ejecucion en Codespaces o en un equipo con Docker.
